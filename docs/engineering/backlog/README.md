# Backlog

Each file in this directory is one work item, per `standards/WORK_ITEM_STANDARD.md` in the Engineering OS. Name files descriptively (e.g. `EPIC-01-onboarding.md`, `TASK-14-fix-duplicate-sync.md`) using the `templates/WORK_ITEM_TEMPLATE.md` shape. This directory is empty by design until real work items exist — that's a legitimate state, not a gap, as long as it stays empty on purpose rather than silently.
